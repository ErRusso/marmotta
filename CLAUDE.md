# Marmotta

## Skills

Project skills live in `.agents/skills/`. Before working on one of the topics below, read the matching `SKILL.md`,
then only the files in its `rules/` directory that apply to the task:

- `.agents/skills/nodejs-core/SKILL.md`: Node-API and native addons, node-gyp builds, native crashes and leaks,
  V8 and libuv internals. This is Marmotta's core domain.
- `.agents/skills/node/SKILL.md`: Node.js with TypeScript: error handling, async patterns, streams, modules,
  testing and flaky tests, performance, logging, and environment configuration.
- `.agents/skills/typescript-magician/SKILL.md`: generic and advanced types, type guards, replacing `any`
  with strict types, and TypeScript compiler errors.
